ST. ANN'S COLLEGE - LESSON PLAN QUESTION GENERATOR

Files:
-Flask
gunicorn
reportlab
python-docx
pypdf
Windows setup:
1. Keep all three files in the same folder.
2. Open Command Prompt in that folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py

The exact supplied letterhead image is shown in the app and at the top of exported PDFs.
The college name and accreditation are NOT typed again under the letterhead.
Question generation remains template-based; PDF and TXT export are included.
